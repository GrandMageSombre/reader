## 踩过的坑（下次别再犯）
1. `ThreadPoolExecutor.map` 一次提交全部任务，熔断 `return` 后 `shutdown(wait=True)` 仍会跑完队列 → 熔断等于没有。改成 `submit + as_completed + cancel`。
2. `store.connect()` 每次 `executescript(SCHEMA)`（2–4ms），万级章节开销超过抓取本身 → 整轮共用一个连接。
3. worker 线程不能碰 sqlite 连接（`check_same_thread`）→ 主线程预读 `local_map` 再传给 worker。
4. 判 `403` 不能用子串：`"共 14030 字"` 会被当风控。用 `(?<![\d.])403(?![\d.])`。
5. 判定顺序：**风控 → WAF 壳 → 锁定 → 空 → 试读 → 长度**。锁定放前面会让熔断永不触发。
6. 试读判定只在正文「短」时才看整页 HTML —— 长章侧栏也常带「订阅本章」。
7. 空目录不能写 `cataloged_at`，否则这本书永远不再被选中（一次签名失败 = 整本丢）。
8. 番茄 `FanqieCrack` 必须注入 `web=Fanqie()`，否则目录/免费章全空且退出码还是 0。
