## 构建关键事实（本机）
- 版本组合：Gradle 9.3.1（腾讯镜像）+ AGP 9.1.0 + Kotlin 2.4.21 + Compose BOM 2026.09.00 + JDK 24。
- AGP 9 默认内置 Kotlin，**不能再 apply `org.jetbrains.kotlin.android`**；本工程走 `android.builtInKotlin=false` + `android.newDsl=false` 保留旧写法（会报 deprecated 警告，能编译）。
- Compose BOM 2026.09 / navigation 2.10 / lifecycle 2.11 要求 **compileSdk 37**；本机 SDK 只有 35/36，已用 sdkmanager 装 `platforms;android-37.0` + `build-tools;37.0.0` 解决（AGP 9.1 只是警告）。
- **沙箱内跑 gradlew 会失败**：`mergeDebugJavaResource` 的 zip-cache 与 `D:\gradle-home\caches\9.3.1\transforms\*.lock` 报「拒绝访问」，且损坏的 0 字节缓存会反复复现；解法 = 删 `app/build/intermediates/incremental` 与 `transforms` 缓存 + **在沙箱外执行构建**（提权）。
