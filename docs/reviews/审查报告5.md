## 三、误报澄清

- 「`findChapter` 的 `!!` 可能 NPE」：`minByOrNull` 只在非空 `indices` 上调用，且已补 `candidates.isEmpty()` 早返回；现由 `在候选目录里定位到目标章` 用例覆盖空列表分支。
- 「`jsonAfter` 处理 `\"` 与嵌套不可靠」：逐字符状态机正确，已加单测（含 `x\"}y` 这种转义引号与嵌套对象）；本轮唯一失败是我在测试里写成两个反斜杠，属测试笔误。
- 「`DeviceCrawl` 在非 IO 线程写库」：`crawl()` 整体包在 `withContext(Dispatchers.IO)`，无此问题。
- 「`failure != null && text.isBlank()` 会吞异常」：异常时 `text` 恒为空串，不会吞；真实问题是「源返回空串不抛」，已按 #2 修。

## 四、测试

- `PaywallAndGlyphTest` 7 → **19** 条：付费判定（含 220 阈值边界）、`needsFallback` 与短章区别、多层卷章前缀、同名章纠偏、空目录、字形表装载/未装载/未知字体回退、起点目录去重、番茄目录展开与补标题、state 抠取（转义 + 嵌套）。
- 全量单测 **81 条全绿**（7 + 22 + 4 + 12 + 11 + 19 + 2 + 4），`assembleDebug` 通过，APK 13.1MB。

## 五、遗留

| 级别 | 项 | 原因 |
|------|----|------|
| P2 | `DeviceCrawl` 先落目录再逐章抓，取消后是「目录新、正文缺」 | 目录是正文缓存键的来源，先落才能边抓边存；取消已能立刻生效，缺的章下次重跑会补 |
| P2 | 付费兜底链路（Repo→采集站）无 JVM 测试 | 需要 Db/App 假件或接口注入，本轮已把纯逻辑抽净，链路测试留待下一轮 |
| P3 | `WebGate` 缓存无 TTL | 目前只缓存 16 条且 `force` 可绕过，风控期影响有限 |
| P3 | `contentCached()` 未切 IO | 现有调用点都在 IO 上下文，暂不动 |
| P3 | `DeviceCrawl` 仍直接持有 `Db`（抓取与落库一体） | 与 `LocalLibrarySource`（读 PC 库）是两条路径，收敛需要先定义统一的 `CrawlResult`，避免本轮扩大改动面 |
