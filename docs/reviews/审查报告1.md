## 二、本轮发现与处置

### P1（严重，已随本轮全部修复 ✅）

| # | 位置 | 问题 | 后果 | 修复 |
|---|------|------|------|------|
| 1 | ReaderScreen.kt:61、DetailScreen.kt:79 | `app.db.progressOf(...)` 在主线程（LaunchedEffect 默认 Main）直接跑裸 SQLite | 书架大时主线程卡顿 / StrictMode 违规 | BookRepo 新增 `progress()`（withContext(IO)），两处调用点改走 Repo ✅ |
| 2 | ReaderScreen.kt `ReaderState.open()` | 无请求序号，快速连点上一章/下一章时慢的旧响应会覆盖新章节 | 显示内容与章节序号错位、进度存错 | `seq` 单调令牌，响应回来先 `if (my != seq) return` ✅ |
| 3 | HtmlSource.kt `abs()` | 未拦截 `#`、`javascript:`、`data:` | `#` 会把详情页当正文抓下来并**永久写进正文缓存**；`javascript:` 直接抛 MalformedURLException | abs() 对这四类前缀一律返回空串，解析结果非 http(s) 也丢弃 ✅ |
| 4 | BookRepo.kt `content()` | 缓存无强制刷新通道 | 首次抓到错误正文后无法自愈 | `content(..., force)`，阅读器错误页按钮改为「重新抓取本章」（force=true）✅ |
| 5 | DetailScreen.kt:113 | 加载失败时「重试」按钮实际是 `nav.popBackStack()` | 名为重试实为退出，错误不可恢复 | 改 `reloadKey++` 触发 LaunchedEffect 原地重跑 ✅ |
| 6 | Browse/Detail/Reader 多处 | `e.message` 原样透传给用户（HTTP 403、Jsoup 报错等） | 用户看到技术报错，不知如何处理 | `Common.friendlyError()` 统一映射（超时/域名/连接/SSL/配置），原始细节不上面板 ✅ |
| 7 | BrowseScreen.kt | 「还没有书源」与「书源全被停用」共用同一空态 | 用户分不清该导入还是该启用 | 按 `app.sources.sources` 是否为空区分文案 ✅ |

### P3（可选）

- Http.kt 编码嗅探只扫前 4KB，GBK 站点的 `<meta charset>` 在 4KB 之后会乱码；书源显式写 `"charset": "gbk"` 可完全规避。
- 站点 HTML 源码里段内换行会把一段拆成多行（排版瑕疵，非错误）。
- Pager 的 footer 在条目很少时会连续自动翻页直到铺满一屏。
- `aspectRatio(0.72f)`、`topInset + 46.dp` 等魔法数字可提常量。

## 三、误报澄清

| 子智能体结论 | 核实结果 |
|--------------|----------|
| 「`available()` 未过滤 enabled，书源全禁用仍会被选中」 | **误报**。SourceManager.kt `available()` 本身就是 `_sources.filter { it.enabled }`，已回读核实；本轮仅把两种空态文案区分开 |
| 「http→https 重定向会丢请求头导致需登录章节失败」 | **误报**。`HttpURLConnection` 内部跟随重定向沿用同一请求头；本应用未使用 Cookie，无此问题 |

## 四、扩展性分析

| 目标能力 | 当前阻碍 | 最小改动路径 | 改动面 |
|----------|----------|--------------|--------|
| 接入非 HTML 来源（自建 JSON API / 私有库） | `SourceManager.source()` 二选一硬编码，`SourceConfig` 无类型字段 | `SourceConfig` 加 `type`（默认 `html`）→ SourceManager 改 `Map<type, (SourceConfig)->BookSource>` 注册表 | 2 个文件（SourceConfig / SourceManager），BookRepo 与 UI 不动 |
| 阅读器仿真翻页 | 正文是 `Column(verticalScroll)` + ScrollState 记进度 | 抽 `ReaderBody(mode)`；分页模式按视口测量分页；进度语义从「章+scroll」改为「章+页」 | ReaderScreen 渲染层 + Db `scroll` 字段语义，书源层不动 |
| 正文 / 目录多页拼接（`/1.html` `/2.html`） | `SourceRules` 无相应字段，`content()` 单次请求 | rules 加 `contentNext` / `chapterPage`，HtmlSource 循环拼接（上限 10 页防失控） | SourceConfig 三处 + HtmlSource 两个方法 |
| 跨源聚合搜索 | 搜索绑定单书源路由 | BookRepo 加 `searchAll(sources, key)` 并发聚合，UI 复用 `Pager` | BookRepo + SearchScreen |
